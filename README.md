# Terminal To-Do List

A simple, command-line based to-do list manager written in Python.

## Features
- Add tasks
- View active tasks
- Mark tasks as finished
- View history with a calendar-like view
- Delete active tasks

## Getting Started

1. Set up your virtual environment if you haven't already.
2. Run the application:
   ```
   python todo.py
   ```

## Project Overview

This project was primarily developed through vibe coding using Antigravity with the Gemini 3.1 Pro (High) model.

The main purpose of this project was to explore vibe coding, understand why it has become popular, and experience how AI-assisted development can support the coding process. Through this project, I learned that vibe coding can be fast, efficient, and useful for reducing the time spent searching through documentation for specific functions, syntax, or implementation details.

However, I also observed that relying too heavily on vibe coding can reduce some of the learning experience that comes from independently solving problems, building logic, and understanding how each part of the program works.

As a student, I understand why vibe coding can be useful, especially when working under time constraints. However, I believe it should be used primarily as a learning tool rather than simply as a shortcut to complete a project. It can help introduce concepts, suggest possible solutions, and speed up development, but students should still take time to understand, review, and modify the generated code.

I also understand why companies may use AI-assisted development in their workflow because of its ability to produce fast outputs and support prompt-based engineering. In this approach, the focus shifts from only writing code to designing effective prompts that guide the AI toward solving a problem.

If I were to vibe-code another project, I would begin by creating a flowchart and then use each part of the flowchart as a guide for writing prompts. In this way, the process becomes similar to structured programming or object-oriented planning, but with a stronger focus on prompt design and problem decomposition.
